# Mfork 0.1.11 for Ubuntu 26.04

## Source history

The Ubuntu build uses the complete history of Gitea's `android` branch at
`d2d1eccbecaf495c2f09bce398f6a2931364966a`, whose release configuration is
0.1.11. Despite its name, this branch contains the shared desktop sources
as well as the Android implementation.

It contains all 38 commits of the previous `master` tip
`c99c210ddbcc0213f8d5d3adc7583b32388d9297`, plus 32 subsequent commits.
Local `master` was fast-forwarded to that source baseline; original commits
and authors were retained. Ubuntu packaging changes are recorded afterwards
as a separate commit. No historical release tags were inferred or fabricated.
The Gitea repositories reported no tags or releases when checked.

The earlier local 0.1.0 package was built from the older master and is
superseded by this build. It was never a tagged release.

## Changes included for desktop users

- Reconnect controller WebSocket streams after interruption.
- Record application errors in the log view and expose core log tails.
- Avoid manual node selection in load-balancing and relay groups.
- Run blocking core startup on a worker thread.
- Retain desktop proxy, tray, startup and privileged systemd service support
  behind desktop-specific configuration and permissions.

## Ubuntu packaging

- Native amd64 `.deb` with mihomo and the systemd helper bundled.
- Explicit WebKitGTK, GTK, AppIndicator, gsettings and polkit dependencies.
- Local packaging without a release updater signing key.
- Matching package, Tauri, application and helper versions checked before build.
- Cargo dependency versions taken from the committed lockfiles (`--locked`).

Build and installation instructions: [Ubuntu 26.04](../UBUNTU.md).
