# 0.1.14 Approved globe-and-route branding

The user selected `design/mfork-orbit-logo-v2.png` and requested a rounded rectangle background. `design/mfork-logo.png` preserves that approved artwork. `design/app-icon.svg` embeds it unchanged and applies a rounded-square clip with transparent exterior corners, so no generated checkerboard pixels enter the icon. The new identity replaces the Tauri starter resources and the earlier Fork candidate.

- Android launcher resources cover five densities, round and adaptive launchers. Adaptive icons use the complete rounded navy tile over a transparent backing with safe-space padding, preserving its rounded corners even on a ROM with a square adaptive mask. The launcher can still impose its outer device-specific mask.
- Notification and quick-settings icons use a simplified monochrome globe-and-node vector. The adaptive themed icon has additional safe-zone padding.
- Desktop icon assets and the sidebar logo use the same approved identity. No Windows installer is produced in this patch.
- Version 0.1.14 / Android versionCode 1014. The 0.1.12/0.1.13 Fork iterations were superseded before final delivery.

Artwork was developed using built-in image_gen; the approved concept and prompts are in `design/mfork-orbit-logo-v2.md`. Packaging uses a deterministic SVG clip to preserve the approved mark and produce real alpha corners.

Regenerate with `pnpm tauri icon design/app-icon.json -o <temporary-output>`, copy the generated root files to `src-tauri/icons`, and merge its `android` resources. For each density, also copy `ic_launcher.png` to `ic_mfork_tile.png`. Retain the source-controlled round/adaptive XML and their tile/monochrome references after generation. Notification/themed vectors are source-controlled separately.

Validation: production frontend and Android Rust builds passed; Gradle ARM64 release and its vital lint checks passed. The APK uses the original signing certificate and versionCode 1014. Rounded desktop/legacy source PNGs are RGBA with zero-alpha outer corners. The final signed package was installed on the connected Android 13 phone for visual verification.
