# 0.1.17 Desktop globe branding

Use the approved enlarged globe and routing curve consistently across Windows and macOS. Tauri's bundle icon list already selects the generated Windows `icons/icon.ico` and macOS `icons/icon.icns`, both derived from `design/app-icon.svg`. The desktop tray uses the application's default window icon.

The shared in-app logo now uses the generated rounded PNG rather than the smaller original design image. Its transparent rounded corners are preserved without adding a second CSS mask.

Windows and macOS icon assets are shared with the repository's existing desktop release workflow. This Windows environment can build an NSIS installer, but cannot validate the macOS Dock or produce a native macOS app/DMG.

Validation: TypeScript/frontend build, service build and Windows release/NSIS packaging passed. The generated EXE reports version 0.1.17; its extracted icon was visually checked against the approved globe. ICO and ICNS decode successfully with transparent corners and their multi-resolution entries. Local NSIS packaging disables updater artifact signing only via a temporary build override; the committed updater configuration is unchanged. This installer was built but not installed over the user's running desktop app.
