# Mfork 0.1.20

- 桌面安装包内置 GeoIP DAT、GeoIP MMDB、GeoSite 和 ASN 数据库，启动时从本地补齐，避免首次启动因数据库下载失败而报错。
- 普通模式和 TUN 服务均支持本地初始化；已有有效数据库与手动更新会保留。
- 关闭 Geo 自动更新，通过设置中的“GeoData 更新”按钮手动更新。
- 损坏的 MMDB 或空文件先备份，再从内置资源恢复。
- 安装服务前预检内置 Geo 资源，避免缺失资源导致现有服务被停用。

## 安装说明

Windows x64 本地 NSIS 安装包，包含重新编译的后台服务。使用 TUN 的用户需重新安装新版提权服务，才能获得服务侧内置数据库。

本地产物不含自动更新签名，不发布远端更新。MMDB 检查用于发现明显截断；DAT 文件只检查非空。
