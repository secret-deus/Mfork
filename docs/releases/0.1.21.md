# Mfork 0.1.21

- 桌面界面通过 Tauri IPC 调用 Rust，由 Rust 统一处理 mihomo 的 REST 请求和日志、流量、内存、连接数订阅。
- Linux 和 macOS 使用 Unix socket 与 mihomo 通信，socket 位于每次启动独立创建的私有目录中；Windows 保留 Rust 后端的本机 TCP 通信。
- 服务模式通过提权服务查询内核状态；界面加载失败时保留内核会话，使停止、重启和关闭 TUN 的操作仍可执行。
- 内核启动检查实际控制器响应；停止或更换内核会话时清理旧订阅。
- Ubuntu 26.04 amd64 安装包内置 mihomo、提权服务和 Geo 数据。发布 tag 会触发对应的 Ubuntu 打包工作流。

## Ubuntu 安装包

产物为 `Mfork_0.1.21_amd64.deb`，SHA-256 校验值见同目录的 `SHA256SUMS.txt`。
本地 Debian 包不包含自动更新签名。打包和隔离测试不会安装或启停本机正在使用的代理服务；实际 TUN 切换仍需另行验收。
