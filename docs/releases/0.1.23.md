# Mfork 0.1.23

- 打通多平台应用内自动更新（OTA）：GitHub 公开仓库恢复为发布宿主，`v*` tag 触發 CI 全平台打包（Windows NSIS / macOS x64+arm64 / Linux AppImage+deb+rpm）、签名 updater 产物并建立含 `latest.json` 的草稿 Release，publish 后应用内「检查更新」即可完成下载、安装与重启。
- 修复 CI 全平台构建失败：`fetch-core.mjs` 匿名调用 GitHub API 在 runner 上被限流（HTTP 403），现读取 `GITHUB_TOKEN`（workflow 已注入）。
- 应用更新走 Rust 命令（`app_update_check` / `app_update_install`）：内核运行时优先经 mixed-port 代理、失败转直连（与内核自升级同一路由策略），下载进度以 `app-update-progress` 事件反馈；更新源在 GitHub 直连之外增加 `gh-proxy.com` 镜像后备。
- 新增 `scripts/release.mjs`：一处命令统一 bump 全部版本清单（package.json / tauri.conf.json / 两个 Cargo.toml 及其 lock）并生成 release note 骨架，消除手动发版漏改。
- Linux 平台差异说明：AppImage 支持应用内自更新；deb / rpm 安装的实例受 Tauri 平台限制无法自更新，需手动换包。

## 升级说明

- 0.1.22 及更早版本安装后，在「设置 → 关于 → 检查更新」可直升本版（endpoint 与签名公钥未变）。
- Ubuntu 自用机器建议改用 AppImage 以获得后续 OTA；deb 继续发布但需手动更新。
- macOS 未配置 Apple 签名证书，更新后首次打开如遇 Gatekeeper 拦截，右键「打开」或 `xattr -cr Mfork.app`。
