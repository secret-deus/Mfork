## Changes

- Keep Android VPN DNS interception enabled for the synthetic DNS server;
  fail VPN startup on self-exclusion or descriptor handoff errors and clean up
  the tunnel when log creation fails.
- Reconnect controller streams, cancel stale retries, preserve controller error
  details, and retain application errors in the log view.
- Use mobile proxy and connection cards, wrapping names, independent filter
  scrolling, and bounded toasts above navigation. Apply native system/cutout
  insets to Android content.
- Remove the generated TV launcher declaration: the app has no TV banner or
  validated remote-control UI. Keep the pre-API-34 tile fallback with a scoped,
  documented lint suppression.
